# qbert-lite

极简 Q*bert 克隆：7 层金字塔，跳到方块上把它变色，全部变成目标颜色即胜利。
躲开追你的 Coily 和乱改颜色的 Slick，用碟子逃生反杀 Coily。

纯 Python 标准库，无第三方依赖。

## 玩法

- 操作：`ul`（左上）`ur`（右上）`dl`（左下）`dr`（右下），每行一个命令跳一格
- 方块有 3 个颜色阶段（`·` → `◍` → `●`），跳上去进一阶，跳一次 +25 分
- 全部 28 个方块变到 `●` 即胜利
- 敌人：
  - `C` Coily：每两步追你一格，碰到即死；用碟子可压死它（+500）
  - `S` Slick：乱跳，把踩过的方块改回初始色
  - `R` 红球：直线往下掉，碰到即死；掉出金字塔 +100
  - `G` 绿球：碰到冻结所有敌人 10 步，+50
- 碟子：`◁` 在第 3 行左侧、`▷` 在第 5 行右侧；从相邻方块跳上去可逃回顶部，
  杀死场上 Coily（+100 逃生分），碟子一次性
- 掉下金字塔或被敌人抓到掉 1 命，共 3 条命

## 运行

```bash
python3 -m qbert_lite            # 交互模式（需要终端）
python3 -m qbert_lite --auto --moves 300 --seed 42   # 无头自动演示
python3 -m qbert_lite --auto --verbose              # 演示时打印棋盘
```

## 真实验证记录

- `py_compile` 通过
- 单元测试 7 项全过：跳跃变色（+25 分）、掉下金字塔掉命、3 次掉命结束、
  红球/Coily 碰撞掉命、碟子逃生（回顶部 + 杀 Coily + 碟子消耗）、Slick 改色、
  全变色判胜
- `--auto --moves 300` 在 seed 42/7/1/99 下全部正常结束（无崩溃、无负生命）
- 无 TODO/FIXME 占位

## 诚实局限

- **无实时键盘输入**：交互是"每行一个命令"的回合制，不是实时动作游戏
- `--auto` AI 只是贪心演示（四个种子分别在 22–78 步内阵亡），Q*bert 本来就难，
  不是刷分工具
- 敌人为简化版：无 Ugg、Coily 出生即追踪（原版是紫球掉到底才变蛇）
- 无最高分存档、无多关卡；Python 3.10+
